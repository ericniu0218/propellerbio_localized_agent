# The meeting transcript reader. It lives in the employee terminal client,
# bedrock-private-ai, so both products share one VTT parser instead of two
# copies. Pinned to an exact commit: change it on purpose and rerun the tests.
# The repo is private, so installing it needs GitHub access (CI uses the
# BEDROCK_PRIVATE_AI_TOKEN secret). The import is guarded: without it the
# server still starts and only meeting_transcripts reports it is unavailable.
#
# Moved forward from d210db6 for three reasons. app/meetings/ needs the
# transcription pipeline (bedrock.meetings.transcribe); d210db6 predates
# "Check that meeting citations point at the line that says it" (00cc9c9) — so
# on the old pin every timestamp in a generated meeting note was unverified,
# and an invented one was indistinguishable from a real one; and it predates
# the summariser fix that stops llama3.1:8b handing its own JSON placeholders
# back as content ("owner": "name or null" reaching a reader as an action item).
#
# Moved forward again from 87061af, which moved diarisation and voice prints
# into that repo but left their arithmetic - cosine similarity over voice
# prints - importing numpy from inside the functions, so a machine without the
# extra crashed where it should have carried on. The fix split the sums
# (bedrock.meetings.vectors, plain Python) from the models.
#
# And forward again for the one that mattered: TitaNet raises above ~123
# seconds of audio, cluster_embeddings fed it a speaker's three longest turns
# concatenated and uncapped, and the exception was swallowed - so whoever spoke
# most in a meeting got no voice vector and could never be matched to an
# enrolled name. Voice enrolment only ever worked on short test clips.
#
# Now at the merge of PR #24, which brings two things from a branch of Eric
# Niu's that had sat unmerged for over a week. Zoom renamed its per-participant
# tracks in 2026 - "audio<Name><recording id>.m4a" inside an "Audio Record"
# folder, where it used to be "audio<digits>_<Name>.m4a" - and matching only
# the old shape meant those tracks went unrecognised and the meeting fell back
# to the mixed recording, throwing away the best speaker attribution in the
# whole pipeline. And every decision and action item now carries who said it,
# read off the transcript at its verified timestamp rather than asked of the
# model.
bedrock-private-ai[speakers] @ git+https://github.com/Bedrock-Technical-Consulting/bedrock-private-ai.git@d3e3342737ee921017041c200a4bc4aa831dd627
